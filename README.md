# Reverse-DNS---PTR-Automation

## How to use:

1 - Create a spreadsheet file with a sheet named "IPs" (mandatory)
2 - Into the sheet "IPs" create a column "IPs"
3 - In the column "IPs" paste the list of IP addresses you want to lookup
4 - Install script dependencies (pip install pandas)
5 - Run the script
6 - When the script ask for the sheet path, paste the full sheet path with no commas
7 - A new spreadsheet will be created at the same directory with the lookups
